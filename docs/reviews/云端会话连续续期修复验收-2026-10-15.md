# 云端会话连续续期修复验收

日期：2026-10-15。用户报告桌面云仓库闲置后显示“无效的认证令牌”。

## 根因与修复

脱敏日志及当前会话记录表明：第一次续期已撤销旧刷新令牌，客户端却仍保存该旧值；下一次访问令牌到期后，自动续期收到 401。云端原接口只返回新的访问令牌，响应 DTO 也不包含新的刷新令牌。访问令牌默认有效期 60 分钟、刷新令牌默认 30 天，闲置后再次访问暴露了连续续期缺陷。

本轮修复：

1. 云端刷新接口原子消费旧令牌并保存新刷新令牌，响应携带完整新凭据；旧值不可重用，并发只能消费一次，签发或落库失败回滚。
2. 个人服务严格校验并原子保存新凭据，再重试原操作；请求合并、原配置路径、服务及凭据对校验，保护新登录、退出和切库状态。
3. 明确会话失效返回 `CLOUD_SESSION_EXPIRED`；暂时故障保留会话，界面只对当前请求代次的终态清云上下文、预览和后台轮询，提供重新登录入口。
4. 设置、设备信息及文件库切换的配置写入与续期互斥，防止旧配置覆回已撤销的刷新凭据；个人资料、版本及共享来源保持独立。

接口契约见[§10.6](../architecture/MVP数据与接口契约.md)。无需数据库迁移；网页 Cookie 会话仍使用独立会话协议。

## 验证方式

修复前，云端真实 API 新测试出现 6 项失败，复现缺失新刷新令牌、失败后未回滚与并发重复消费；个人端测试复现不完整响应被当作成功及失效/暂时故障混淆。独立复核又复现设备信息保存覆回旧凭据，新增并发回归后修复。

真实端到端测试使用独立云服务、个人服务、临时账号与资料、随机本机端口，注入正确签名但已到期的测试访问令牌，直接跨过小时等待，验证三轮连续云端及个人代理续期。Electron 使用生产 `file://` 页面验证搜索、文本预览、失效提示、真实轮询取消、重新登录返回原页面，以及个人资料与两端版本数量不变。

本轮测试不使用默认 9000 云库或真实个人资料执行增删改，不读取用户密码，也不将真实凭据输出到日志。
