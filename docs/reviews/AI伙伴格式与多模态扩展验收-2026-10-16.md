## 1. 实际交付

- 增加 PPTX 幻灯片文字及表格、ODT/ODS/ODP、CSV/TSV 单元格、HTML 正文解析；兼容常用宏和模板变体，不执行宏、公式或脚本。CSV 和 HTML 原有按普通文本读取，本次改为结构化或清洁正文，不把它们描述为从未支持过的新扩展名。
- Word 兼容已知 Strict OOXML，补取 DrawingML 文字、修复文本框重复；文字和内嵌图共用正文锚点。PPTX 按实际展示关系排序，不按成员文件名排序。
- `document_overview` 提供真实引用的内嵌位图清单，`read_embedded_images` 按实际 image_id 读取；支持 DOCX/XLSX/PPTX/ODT/ODS/ODP 及对应别名。图片通过真实 PNG 输入交给同一模型，不另设服务或第二套密钥。
- 只有实际内部引用的支持图片会进入工具；外链、未引用媒体、备注/注释中未承诺读取的辅助图片和嵌入对象不冒充正文。Word/ODT 图片保留正文结构锚点，不伪造原页码，不宣称完整 Office 页面排版。
- 图片经受限子进程解码、缩放和重新编码。透明底先叠白底，保留黑色图形和线路。PNG/JPEG/GIF/WebP/BMP/TIFF、PDF 原页和多帧图片保持可读。
- 零文字单元明确提示实际缺口和下一步，可继续检查内嵌图或原页；无真实来源时仍拒绝模型自造引用。读到非空资料的末尾不误报成全文不可读。
- 设置新增“测试图像理解”：主动发送现场随机合成的颜色/形状图，本机核对实际回答，不读取个人资料。结果只表示当前配置本次简单识图表现，配置变化即清空，不持久宣称复杂图纸能力。
- 解析器升级至 v2，旧派生索引重新排队；不改写资料、身份、历史版本。收录和建立本机索引不自动调用外部 AI，图片分析结果未自动写入全文索引。

## 2. 复核与修正

| 复核发现 | 已落实修正及回归 |
| --- | --- |
| ODS 合法百万重复空行或大片空列使前文也无法返回 | 空白区数学计数并推进坐标；只对非空内容展开，超限保留前文并报告 partial |
| ODS 重复行反复生成同一大段空格文字 | 单元格解析缓存，空白跳过；非空展开另受 50000 格、100 万字符工作预算限制 |
| Word 文本框导致后续图片与正文段落编号错位 | 共用 `_word_body_blocks`；嵌套内容归所属外层段落，图像只登记一次 |
| ODT 注释、脚注导致正文与图片编号错位 | 共用 `iter_odf_body_paragraphs`，视觉遍历排除辅助内容 |
| 透明底黑色图片直接转 RGB 后全黑 | RGBA/调色板透明图先叠白，再转 RGB；独立图片和 DOCX 嵌图四种组合回归 |
| Office 重复结构目标可反复解压同一 XML | 幻灯片、工作表、绘图目标拒绝重复展开；正常图片复用保留 |
| ODT 无效外链在逻辑重复区反复遍历，成功图片数量上限不能约束 | 全局累计 100000 节点工作预算，含无效引用及重复呈现；超过时明确剩余未读 |
| 渲染 stdout 在父进程内无界累计 | 使用匿名临时文件，子进程 FSIZE 与父进程读取量双重限制，保留超时/取消/CPU 约束 |

所有新增主要行为先用合成资料证明 RED，再落实实现并验证 GREEN。Python、JavaScript、通用和安全独立复核已完成，无剩余阻断发现。最后 ODT 放大样本包含 50 万逻辑引用，受节点预算限制，约 49 毫秒结束；这不是一般资料性能承诺。

视觉工具每次最多 3 张或 3 页；单任务累计交付最多 24 张或 12 MiB PNG，重复读取计入并随检查点保留。传输正文单次最多 16 MiB、单段累计 64 MiB，包含模型历史重复携带的图像；发送前拒绝超量，不自动重试收费请求。检查点不保存图像字节，续做按需重读并重新核验固定版本。
