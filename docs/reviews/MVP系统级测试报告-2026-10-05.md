# TeamHub 本地与云端系统级测试报告

日期：2026-10-05。范围：当前 MVP 本地桌面、个人服务、云服务、独立网页、管理员入口及交付包。测试基于当前工作区，而不是仅重用上轮验收结论。

## 1. 结论与环境

本地 **232 项**、云端 **98 项**、启动器 **12 项**、桌面后端进程管理 **3 项**通过，共 **345 项自动化用例**。另执行桌面八组界面流程、独立 Chromium 完整流程与竞态专项、独立云包和实际 macOS 桌面包测试；最终产物均通过，详见第5节。

环境为本机 macOS ARM64、Python 3.11、SQLite、Electron、Chromium。所有服务使用临时数据库、合成资料、独立 profile；未迁移或修改真实个人库、组织云库，未停止用户已有服务。桌面产物测试刻意占用测试端口，检查应用选择可用端口及退出时仅回收自身后端。

测试发现的团队权限漏洞、无效合并入口已修复；修复后重新执行对应界面、后端全量回归，并重新生成云端和桌面包。旧测试过时和测试定位错误均单独登记，不当作产品功能通过或产品缺陷。

## 3. 本轮发现及处理

### 3.1 团队角色权限漏洞（已修复）

原成员接口接受任意角色字符串；团队admin能够把自己提升为owner、降级原owner或邀请新的owner；最后一名有效owner也能降级。新增用例先复现 **6 项失败**。

修复后仅接受四种合法角色；owner授予/变更只由owner执行；转让先建立另一有效owner，最后有效owner不得降级；停用账号不能被邀请或获得所有权。读取操作者及检查owner数量均置于SQLite写事务内。补充两owner并发自降级断言：一项成功、一项409，最终仍有一个owner。请求前屏障不保证内部执行点完全交错，不夸大为所有并发调度证明。

新增 `cloud_backend/tests/test_system_management.py` 共9项通过，并纳入云端98项全量回归。独立Python/权限静态复核通过。

### 3.2 待整理无效合并入口（已修复）

“合并为版本”按钮原先仅弹出“功能迁移至云端同步”的消息，没有实施合并。移除无效按钮、对话框和死逻辑，保留智能扫描的名称相似分组，明确只是核对线索。未把跨对象合并当成已实现功能，也未自动修改资料身份。

导航界面新增智能扫描、全选后不出现该无效入口的断言；本地版本保存、恢复、删除继续正常。

### 3.3 旧测试维护与断言增强

- M2/M3旧脚本仍期待路径prompt、复制源文件、恢复时生成v3、待整理可收藏。按现行规则改为收录对话框、移动源文件、直接恢复v1且历史数不增加、只有已整理资料可收藏。
- M4预览文案更新；M5发布fixture补充明确visibility，不绕过新增权限要求。
- M2/M3恢复后增加直接读取工作文件内容的断言，避免只改元数据也被误判通过。
- 新增标签维护、扫描与批量恢复API闭环；标签建议按现有“三份同类型资料”规则准备fixture。
- 实际打包测试增加主窗口/悬浮窗原生File拖入，经过正式preload与IPC，而非直接调用收录API冒充拖拽。首次补测的悬浮窗DOM选择器写错，修正为floatingBtn后复测。

## 4. 可复跑命令与日志

从项目根目录运行，真实桌面/浏览器测试需要本机GUI及回环监听权限。命令只使用脚本创建的隔离环境。

```bash
npm run frontend:build
venv/bin/python -m pytest backend/tests -q
cloud_backend/venv/bin/python -m pytest cloud_backend/tests -q
venv/bin/python -m unittest discover -s scripts -p test_mvp_launcher.py -v
node --test scripts/test_m6_backend_manager.cjs
env -u ELECTRON_RUN_AS_NODE node_modules/.bin/electron scripts/test_library_navigation_ui.cjs
node scripts/test_cloud_web_ui.cjs
node scripts/test_cloud_web_ui.cjs --races-only
venv/bin/python scripts/test_cloud_package.py
node scripts/test_m6_packaged.cjs
```

网页脚本需要已安装Playwright及其Chromium；本轮通过 `PLAYWRIGHT_MODULE` 指定本机已有模块，不新增项目依赖。其余桌面脚本为 `test_m2_ui.cjs`、`test_m3_ui.cjs`、`test_m4_ui.cjs`、`test_m5_ui.cjs`、`test_organize_ui.cjs`、`test_storage_migration_ui.cjs`、`test_delivery_ui.cjs`，执行方式与navigation一致。

## 6. 验证边界

本轮结论是当前macOS ARM64 + SQLite环境下，已覆盖的MVP流程通过。未进行Windows/Linux安装验收、真实内网HTTPS部署、十人长期试用、大容量压测、物理断电及跨网段故障验证。云网页与桌面原生File拖入由自动化驱动；没有把它称为人工从Finder逐次拖入或系统文件选择器全面兼容测试。并非保证系统在所有环境和输入下零缺陷。

已有云库仍按[迁移指引](../guides/云端与投递启动及迁移指引.md)升级到005；本轮角色接口收紧不需要新增数据库迁移。桌面包未做Apple发行签名/公证。执行与交付没有改动真实资料或自动部署生产服务。
