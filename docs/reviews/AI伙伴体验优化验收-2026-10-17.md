## 1. 交付内容

- 回答方式新增「深入思考／快速回答」，与快速、标准、深入、自定义的任务预算分开。每轮准备冻结选择，不改全局 AI 配置。DeepSeek 工具链通过 SDK 正确回传本轮推理字段，原始思考内容不展示、不落库、不带入下一轮。
- SDK 真正接收流式响应，逐步展示结构化回答的文字片段。未核验片段标明「正在生成 · 引用待核对」，只保存在当前任务内存；完成、失败、暂停、停止后清除。最终来源、版本和依赖校验后，才追加一次正式助手消息。
- 回答、阶段分析和 Markdown 成果支持标题、列表、强调、表格与代码。采用锁定的 markdown-it 15.0.3，禁用原始 HTML 和图片语法，不自动加载模型提供的远程图片。HTTP(S) 参考链接由用户点击后经受限桌面桥打开，系统打开失败显示安全提示；其他协议拒绝。
- 工作过程默认收起，摘要显示最新动作，可展开核对完整步骤。回答引用与来源按钮、来源弹窗均显示 `[S#]`，支持恢复后不连续的来源编号。
- 完整对话保存在当前个人库。本轮发送近期最多 16 条／18000 字原文；较早消息按完整句段规则形成最多 12000 字的明确原文摘录并附消息 ID，没有额外模型总结请求。摘录有省略，不能等同于完整语义记忆。
- 普通追问可接续最近完成任务的实际文字证据，最多 100 个来源、60000 字完整单元，省略明确说明。只有本轮仍授权且固定版本、状态与元数据一致的资料可恢复；失效资料相关旧消息也过滤。准备界面展示实际会再次外发的文字。
- 普通新轮不继承旧草稿、图像消耗和任务用量；暂停续做仍沿用原有完整检查点和已确认预算规则。新 v3 检查点支持稀疏 S 编号及递增高水位，兼容有效 v1/v2；原有 180000 字／1 MiB／1000 来源硬上限保持。
- fetch SSE 携带现有本机能力凭证，事件发送完整任务快照；监听断开只停止订阅，不取消任务。45 秒没有活动后回退状态查询，不重发模型任务。数据库读取使用短会话，等待和推送不持有会话或切库锁。

## 2. 独立复核及修正

| 发现 | 已落实修正 / 回归 |
| --- | --- |
| 旧 SSE 先检查库绑定、再从当前库取得任务会话，切库时同 UUID 可能读到新库内容 | 绑定校验与短会话建立在切库锁内原子完成，序列化后推送前再次核验；两个真实临时 SQLite 库保留同任务 UUID，初次与后续读取交错均只返回库已变化 |
| Markdown 参考链接在 Electron 中被默认拒绝新窗口策略拦住 | 增加显式 `openExternalLink` IPC；仅可信主窗口的本机主 frame 可以调用，规范化 HTTP(S) 并拒绝危险协议、凭据、控制字符和超长地址，保留原有拒绝弹窗策略 |
| 正文使用 S 编号，来源按钮与弹窗无法按编号对应 | 按钮和弹窗显示固定来源编号，真实桌面流程核对编号及详情 |
| 停止请求确认期间仍可刷新进度，迟到的 running 响应使已停止任务在界面恢复运行 | 按钮与行为函数同时阻止停止／启动确认期间刷新。新增确定性回归先出现 `1 !== 0` 的有效 RED，修复后 GREEN；停止后不恢复运行、不继续轮询 |

模型流式、思考、上下文及检查点等主要行为均先执行有效 RED，再实现生产逻辑。Python、JavaScript、通用与安全复核采用限定范围检查；实际结果记录在本轮收尾说明与测试日志中。不操作只读 `.git`，不创建提交。

12 组流程覆盖以下实际行为：

1. 上游尚未结束时出现流式预览，正式消息尚不存在；最终 Markdown 表格与代码正常，HTML 和远程图片不执行，原始思考不出现在界面。
2. 自主搜索、读取两份固定版本、生成说明草稿；未确认零模型请求，重复启动复用任务。
3. 确认成果进入待整理并建立 V1，重复保存无冗余，原资料不变。
4. 快速回答独立于预算，追问经确认直接使用恢复的真实文字证据及来源，零重复读取；刷新后保留会话和成果。
5. PDF 原始页与独立图片实际以 PNG 进入模型请求，固定版本及页码可核对。
6. 停止模型任务后不采纳迟到回答。
7. 限流安全报错、零自动付费重试、日志不出现测试密钥，页面无异常或自动外部网络请求。
8. 自定义预算暂停后保留来源、草稿和全文证据，刷新并重新确认后继续同一任务，重复续做不多发请求。
9. XLSX 结构浏览与行块读取，三次模型请求核对 400 个单元格。
10. 纯图 DOCX 内嵌位图、PPTX 正文、CSV 与 ODS 的真实读取及固定来源。
11. JPEG/GIF/WebP/BMP 实际解码，双页 TIFF 读取第二帧并检查实际 PNG 像素。
12. 只有主动点击设置测试时才发送随机合成图片，未上传个人资料。

上述流程使用真实 SDK、解析器、资料服务、冻结后端和生产页面，模型端点为本机假服务。参考链接点击经桌面桥记录验证；IPC 主进程测试 mock 系统浏览器，未实际访问外部网站。工程机制通过不能证明实际 DeepSeek 与官方产品体验相同，不能证明复杂图纸分析正确。

## 4. 产物与复现

本轮应用位于 `dist-electron/ai-partner-experience-2026-10-17/mac-arm64/TeamHub.app`。正常退出旧 TeamHub 后再打开此包，进入「AI 伙伴」。根目录旧启动入口及历史测试包保留，不自动切换到本版；试用应用沿用正常个人配置，验收使用专用临时配置，没有改动真实用户库和钥匙串。

```text
backend/teamhub-backend  ba7c4b19ee98b64b8dd5e9d332a9ed9a0435147f4aa6fb35fb60486895138897
app.asar                d1c2b60fea61952fde6b47a844bc921f08ae272bfaf4594e469678ec4ad1a8ca
```

包内后端摘要与 `dist/backend/teamhub-backend` 一致。报告、截图、trace 和日志副本归档于仓库忽略目录 `.mvp-sandbox/experience-2026-10-17/`，不是运行依赖，不包含真实用户资料。

端到端需要本机端口和 Electron 图形环境，最后一项需先构建对应应用。未调用真实收费 AI，未验证 Windows/Linux 或真实内网环境；云端未改，本轮未重跑云端全套。长期用户记忆、历史搜索工具、自动学习 Skill、真实长会话语义压缩、组织 AI 检索和原件任意编辑留待后续。格式与多模态能力仍以使用指引中的实际能力表为准。
