# AI 辅助整理使用指引

第一期（2026-10-15）：个人端调用 DeepSeek API，为用户主动选择的单份资料生成标签建议和简短摘要。摘要供阅读，标签经选择后填入现有编辑表单。原文件、描述和内容版本不由 AI 改写。

**新增后台预整理（2026-10-21）：** 待整理中可按批次或主动开启的当前库范围，提前准备名称、标签和分类方案，再由用户一次确认入库，见[AI 预整理指引](AI预整理使用指引.md)。本页保留原有「AI 辅助整理」单份标签建议入口的操作，两者的内容来源与确认方式不同。

后续增加的[资料内容索引](资料内容索引使用指引.md)沿用同一服务配置，但以已保存版本为依据，辅助词独立保存用于搜索；本页的「AI 辅助整理」仍读取当前工作文件并提供人工选择的标签建议。

## 配置服务

1. 退出旧桌面后，通过根目录 `启动TeamHub.app` 打开更新包。
2. 进入「设置 → AI 辅助整理」。默认服务地址为 `https://api.deepseek.com`，默认模型为 `deepseek-flash`。地址填写基础地址，程序会追加 `/chat/completions`。
3. 将在 DeepSeek 开放平台自行创建的 API 密钥填入密码框，点击「保存 AI 设置」。不要将密钥发给协作者或粘贴到项目文件。
4. 点击「测试连接」。它会发送一条简短测试消息，可能产生少量费用，不读取或发送资料。

macOS 正常桌面运行时，密钥存放在系统钥匙串，页面仅显示是否已配置。AI 设置属于本机设备，切换、迁移或备份个人资料库不会带走密钥。服务地址变更时须重新填写对应密钥，避免旧密钥被发送到另一服务。

沙箱和不支持钥匙串的环境使用本次个人后端进程内存，重启后须重新填写；也可通过运行环境提供 `DEEPSEEK_API_KEY`。设置页会明确显示实际保存方式。清除功能会停用本机 AI 密钥；若系统拒绝清理钥匙串，会明确提示已停用但存储清理失败。环境变量的删除需由启动环境维护者完成。

第一期验证 DeepSeek 格式的接口；服务地址可配置不代表已验收所有兼容平台。本机 HTTP 地址仅用于隔离测试；其他地址要求 HTTPS。

## 单份资料整理

1. 在待整理资料的单项整理窗口，或文档详情的标签编辑区，点击「AI 辅助整理」。
2. 系统在本机读取当前工作文件，展示待发送摘录、资料名称、目标服务与模型。这一步不调用外部 AI。
3. 核对摘录和截断提示，用允许外发的非敏感资料试用。勾选同意后，点击「生成标签建议与摘要」才会发送。
4. 阅读摘要，勾选认可的标签，点击「填入整理表单」或「填入标签编辑区」。默认没有预选标签，原有标签会保留。
5. 回到原窗口，按原有「完成整理」或「保存标签」按钮确认保存。填入建议本身不修改数据库。

AI 读取的是当前工作文件，可能包含尚未保存为版本的修改。准备内容有效期 10 分钟；更改文件、名称、当前版本、个人库或服务配置后，可能需要重新准备和确认。关闭窗口只取消等待，已经送达服务商的调用仍可能产生费用。

摘要不保存为资料描述、不写原文件，也不生成版本；标签未采用时不会产生标签对象或自动完成整理。整个个人库的标签词表不发送给模型，已有名称的匹配在本机完成。

## 格式与限制

| 格式 | 第一期范围 |
| --- | --- |
| TXT、Markdown、CSV、JSON 等文本 | 安全解码后读取文字 |
| PDF | 有文字层的文档；前 20 页范围内提取，受展开与计算上限保护 |
| DOCX | 正文和表格文字；不执行宏或外部链接 |
| XLSX | 有限工作表和单元格的文字/缓存值；不执行公式或外部链接 |
| PPTX、ODT/ODS/ODP、CSV/TSV、HTML（2026-10-16 扩展） | 复用新版内容解析器提取正文、表格或幻灯片文字；HTML 不运行脚本或加载关联资源，模板/宏变体只读正文 |
| 扫描 PDF、图片、旧 DOC/XLS、压缩包、整体文件夹 | 暂不支持，明确提示后由用户按原流程整理 |

单文件最多 10 MiB，待发送正文最多 12000 字符。触及页数、工作表或内容限制时会提示截断；摘要只覆盖展示的内容，不表示已完整阅读整份文件。具体表格、归档与 PDF 保护限额见接口契约 §10.7。

## 故障与费用

密钥错误、余额不足、请求限流、网络故障、超时和格式异常会给出不同提示。系统不在后台自动重试付费请求；重新读取内容、再次确认后才发起新的分析。成功的同一准备任务可复用结果，避免重复点击重复收费。

接通接口不等于标签准确或节省时间已经得到证明。第一期应观察标签采纳情况、人工修改次数和整理耗时，再决定是否扩展自然语言搜索、版本变化说明与跨资料问答。

当前自动化验收使用隔离模拟服务。真实 DeepSeek 余额、网络和实际生成质量须在用户自行配置密钥后验证，项目没有内置可用密钥。

参考：[DeepSeek API](https://api-docs.deepseek.com/)、[JSON 输出说明](https://api-docs.deepseek.com/guides/json_mode/)。
