# 共享资料库使用指引

更新：2026-10-14。桌面端和云端网页遵循同一选择规则。

## 登录与进入

桌面端打开 **设置 → 云服务**，保存服务根地址，例如 `http://127.0.0.1:9000`，然后登录。网页直接访问该服务的 `/cloud.html` 并登录。

登录后进入 **云仓库**：只有一个资料库时自动进入；有多个时点击资料库卡片。以后会恢复该服务、该账号上次成功进入且仍可访问的库。首次使用或原库权限失效时需要重新选择，不会自动选列表第一项。

顶部 **共享资料库** 显示“组织 / 资料库”；需要换库时直接在此选择，无需到设置绑定或保存。资料投递使用此处选择的库及其成员。

没有资料库时联系组织管理员开通权限；加载失败可重试。组织及资料库管理入口与普通浏览分开，管理页面切换组织不会改变云仓库当前选择。

## 发布与更新

从本地文档库选择 **发布 / 更新共享资料**：

- 发布新资料：在对话框直接选择 **发布到** 的资料库，再核对共享范围、成员和标签。对话框选择不会切换云仓库的浏览位置。
- 更新原资料：核对窗口显示的原组织、原资料库和云端资料。目标固定为已有关联；即使正在浏览另一资料库，也更新原位置。没有贡献权限时不可更新。
- 响应丢失后的重试：沿用已确认的内容、资料库和成员，不把同一请求改投其他位置。

发布取当前工作内容并冻结为本次请求，实体查重和版本保护仍适用，详见[推送与取回查重](推送与取回查重.md)。

切换资料库不会移动个人资料或自动发布，也不会改变已有云端资料的来源。切换账号不等于切换个人文件库。当前客户端一次连接一个云服务；换服务地址后需重新登录。

## 获取更新

退出已运行的 TeamHub 再通过 [启动TeamHub.app](../../启动TeamHub.app) 打开；云网页刷新即可加载已部署的新前端。云服务启动与账号开通见 [MVP访问与测试指引](MVP访问与测试指引.md)。
