# AI 智能伙伴使用指引

**最后更新：2026-10-23**

AI 伙伴可以持续交流、查找和阅读个人资料、比较分析内容，并生成可保存的文本成果。它使用 TeamHub 已保存的资料版本；工作文件中尚未保存为版本的修改不在本轮读取范围内。

## 1. 进入与配置

当前版本：[打开本轮 TeamHub.app](../../dist-electron/document-cards-2026-10-21/mac-arm64/TeamHub.app)，保留自然交互和[待整理 AI 预整理](AI预整理使用指引.md)，新增[资料卡生成、检索与更新](AI资料卡使用指引.md)。已完成构建、原有聊天回归与桌面工程验收，根目录启动入口优先打开这版。先从旧 TeamHub 菜单正常退出，再打开本轮应用。新版沿用正常的个人配置和资料库；工程验收使用独立临时配置，不修改用户资料。此前 [2026-10-19 自然交互包](../../dist-electron/ai-natural-chat-2026-10-19/mac-arm64/TeamHub.app)作为历史交付保留。

打开包含本轮功能的 TeamHub，在顶部导航进入「AI 伙伴」。也可在资料详情点击「与 AI 讨论」，将该资料预选到新对话。选择资料和打开页面不会调用模型。

进入「设置 → AI 服务」，填写服务地址、模型和 API 密钥并保存。伙伴复用既有 AI 配置；macOS 密钥由系统钥匙串保护，页面不回显，资料库和共享副本不保存密钥。沙箱测试使用内存密钥，重启需重新配置。

Hermes 是随 TeamHub 一起提供的本机任务引擎，无需单独安装、启动或填写第二套密钥。它负责组织模型与资料工具的协作，回答仍由你配置的模型服务生成；使用 DeepSeek 时，模型请求仍发往 DeepSeek。输入框下方显示实际模型和模型服务地址，不会因 Hermes 在本机运行而把外部模型调用变成本机推理。

模型必须支持工具调用；共同阅读图片、扫描件或 PDF 原页还需要图像输入能力。服务支持的格式和质量取决于实际模型，连接测试成功只表示简短文本请求可用，不能证明所有工具和图像能力均可用。测试连接本身可能产生少量费用。

点击“测试图像理解”，系统会生成一张随机彩色几何图，请当前模型识别后由本机核对。该测试只发送合成图片，不发送资料，可能产生少量费用。结果仅代表本次简单图像测试，修改配置后须重新测试；失败时可区分识别不匹配和连接、权限等错误。当前默认 `deepseek-flash` 已提供图像输入，见[官方说明](https://api-docs.deepseek.com/guides/vision/)；自定义模型请以实际服务为准。

个人伙伴不依赖组织云端服务启动。使用外部模型时，点击发送会将本次问题、有效历史及按需读取内容发给页面显示的服务；本机运行的资料工具负责取材和权限控制。

## 2. 开始讨论

1. 输入问题，点击「发送」或按 Enter；Shift + Enter 换行，中文输入法选字不会误发送，⌘ / Ctrl + Enter 也可发送。无需准备、勾选和再次确认。
2. 默认快速回复，需要更充分推理时开启「深度思考」。它与任务总预算是两项独立设置。
3. 根据问题选择可用资料：
   - 「所选资料」：只读取选择的资料。未选文件时可以自由交流。
   - 「整个个人库」：允许按需检索待整理和文档库，不会一次通读全部资料。
4. 回答逐步显示在对话中；有需要时展开「查看处理过程」查看实际搜索、阅读和用量。

输入框下方显示模型及服务地址。发送代表允许该服务按当前范围处理问题和相关资料；配置密钥本身不开放全库。范围和回答方式随会话恢复，每个新问题使用发送时的已保存版本。服务在其他页面被更改时，先刷新说明，再由你重新发送。

「高级选项」可调整总预算，通常无需修改。新配置默认最多 64 次模型请求、160 次工具调用、128000 输出 tokens、30 分钟；已有合法预算偏好继续保留。内部执行段在同一总额内自动衔接，不会每段弹窗，也不代表会用完整个额度。实际费用由模型服务计费；到达总额时保留进度，可继续或提出新问题。

## 3. 可以怎样提问

- 「帮我找到青川项目相关的验收资料，先说明哪些最值得阅读，再梳理尚需核实的事项。」
- 「比较这两份资料的要求与记录，引用原文，指出一致和不一致的部分。」
- 「一起阅读这份 PDF 的第 3、5 页，结合线路图和文字说明分析，区分图上事实与推断。」
- 「基于上面的讨论，生成一份培训说明草稿，保留资料出处。」
- 「继续上轮讨论，如果考虑这个补充条件，你会怎样调整建议？」

普通交流不强制选择文件。涉及资料事实时，伙伴应实际读取相应内容，并给出来源；搜索结果是候选线索，不能据此声称已通读文件。

已有资料卡时，伙伴可先用卡片摘要、内容导航和用户补充判断相关性，再读取所需原文。卡片属于已保存的 AI 理解，其旧来源编号不会直接变成本轮引用。问题涉及具体参数、条款或结论时，仍需核对相应原文；没有卡片的资料也可照常搜索和阅读。

2026-10-23 起，伙伴搜索与资料列表共用多词相关性检索，返回原文位置、命中来源和索引覆盖；伙伴可从命中位置继续阅读。搜索候选本身不生成事实引用，实际读取后才建立依据。当前仍是词法检索，模型可以改写查询，但尚未接入向量语义召回；索引不完整时，未命中不等于不存在。实现边界与独立桌面包见[第一阶段验收](../reviews/AI整理与准确检索第一阶段验收-2026-10-23.md)。

## 4. 核对依据与覆盖

回答中的 `[S1]` 等编号对应本轮实际使用的读取来源，来源卡片显示相同编号。普通追问接续已读文字时保留原编号，编号可能不连续。点击资料依据，可查看名称、固定版本、原文位置及摘录；再进入资料详情核对原件或历史版本。资料详情展示当前状态，不能把它自动等同于回答引用的历史版本。

生成中的回答会逐步出现，并标明「正在生成 · 引用待核对」。这是未完成内容；完成后展示正式回答及可核对来源。停止或连接失败会保留已生成内容并标明未完成，不冒充最终结论。回答、阶段分析和 Markdown 草稿支持标题、列表、表格及代码显示，HTML 不执行、远程图片不自动加载；参考链接仅在点击后由桌面应用校验并打开 HTTP(S) 网页。

本轮按授权时的当前已保存版本阅读；没有开放任意历史版本的自动探索。多份资料比较可以使用各自冻结版本。资料在运行中删除、改版或整理信息改变后，旧内容不能继续外发或采纳为新答案。

<a id="reading-formats"></a>

本轮阅读能力如下。文件可被 TeamHub 收录，不等于其中所有内容都能被 AI 读取。

| 资料类型 | 正文及表格 | 图像阅读与边界 |
| --- | --- | --- |
| PDF | 有文字层的正文与页码 | 按实际页码查看原页，扫描件也可看图；不自动生成 OCR 全文索引 |
| Word DOCX | 段落、表格、文本框与 DrawingML 文字，兼容 Strict OOXML | 可读取正文真实引用的位图；不还原整页布局，页眉页脚和嵌入对象有缺口 |
| Excel XLSX | 工作表与单元格，按行块读取，公式只读已有缓存 | 可读取工作表真实引用的位图；原生图表、形状与布局未还原 |
| PowerPoint PPTX | 按展示顺序读取幻灯片文字、表格 | 可读取幻灯片真实引用的位图；母版、布局、演讲者备注与矢量组合有缺口 |
| ODT / ODS / ODP | 开放文档正文、表格或幻灯片，重复行列有安全展开上限 | 读取实际引用位图，保留结构锚点；不保证整页排版与重复呈现 |
| CSV / TSV | 按分隔符、引号与换行读取逻辑单元格 | 无页面图像，保留原始值，不执行单元格文字中的公式 |
| HTML / HTM | 提取正文块，排除脚本、样式标签、hidden 属性及内联隐藏内容 | 不加载 CSS 样式表、图片、外链、iframe，不复原网页布局 |
| TXT / Markdown 等文本 | 按原文行读取，支持 UTF-8、带 BOM 的 UTF-16、GB18030 | 无页面图像 |
| PNG / JPEG / GIF / WebP / BMP / TIFF | 不自动生成文字索引 | 直接看图；GIF、TIFF 可指定帧，作为图片页编号 |

常用宏和模板变体按对应 OOXML/开放文档正文读取：DOCM/DOTX/DOTM、XLSM/XLTX/XLTM、PPTM/POTX/POTM/PPSX/PPSM、OTT/OTS/OTP。宏、脚本和公式不会执行。旧二进制 DOC/XLS/PPT、原生 WPS 二进制、CAD、SVG/HEIC 视觉及音视频暂不支持；请真实另存为 PDF 或对应受支持格式，改扩展名不能转换格式。

PDF 或独立图片每次最多读取 3 页，办公文档内嵌图片每次最多 3 张。页面或图片可能缩放，只有实际读取内容构成视觉依据；段落内的图片不等于完整 Word 页面。单任务图像交付还有累计数量和容量限制（重复读取也计算），传输包括历史中的重复图像，接近容量时向伙伴返回缺口信息，优先利用已有证据收束回答；需要更多图像时可缩小范围后发起下一次问题。

本机索引只自动提取上述可解析文字。纯图片 Word 的文字单元可以是 0；伙伴仍可从结构总览发现内嵌位图并请求看图。普通对话看图不会自动把 AI 推断写入索引。主动生成资料卡后，卡片中已识别并保留的内容可以参与查找；未理解的扫描内容仍不能保证通过图中文字检索到。

较大资料先查看结构，Excel 按工作表与行块批量读取，步骤显示已读行或单元范围。单次内容过长时继续沿下一位置读取；只获得结构、行数或表头不代表已读整张表。连续检索或阅读没有新增证据时，系统先向伙伴返回反馈，让其调整方法或解释缺口；正常翻页继续取得新内容不属于无效重复。

当前检索使用名称、标签、描述、已建立的正文索引，以及当前有效的资料卡与人工补充。伙伴能主动换关键词补查；未命中不证明全库没有相关资料，未建立正文索引的内容可能无法按正文发现。当前尚无向量语义索引，也未接入组织资料直接检索。

## 5. 保存成果与持续交流

需要可保存成果时，请明确要求「生成说明／报告草稿」。草稿显示在对话中，可以展开预览。点击「确认收录到待整理」并确认后，TeamHub 才建立新资料和初始版本；源资料不被覆盖。重复保存同一成果返回已有资料，不制造重复版本。

当前支持 Markdown 和 TXT。草稿带资料来源说明，保存后仍可在会话外核对其依据。继续按正常流程整理、加标签或主动共享生成的资料。接入 Hermes 不代表已经开放任意本机文件操作或原生 Word／Excel 加工；当前仍使用 TeamHub 提供的资料读取和草稿工具。

完整对话保存在当前个人库，重新进入后可继续。Hermes 接续经过校验的原生对话消息、工具调用及有效证据；必要的模型协议字段仅保存在本机私有任务状态，不显示为回答。较长上下文由引擎管理，发生压缩时仍使用当前模型服务并计入任务用量。

当相关版本、资料范围或服务发生变化，系统会回退到仍有效的文字历史，并按需重读资料。一般对话目标可以继续保留，失效证据不能当作当前事实。缩小资料范围后，原范围相关的用户文字、助手转述和历史摘录也会从后续模型输入中排除，本机原始记录仍保留。旧图像按需重读，不无限保存和重复发送图片字节。切换会话后，已开始的任务继续运行，稍后可回来查看。

长期用户记忆、会话历史搜索工具和自动学习 Skill 尚未开放。

## 6. 停止与故障处理

- 点击「停止生成」会终止后续处理，已显示的文字保留并标记未完成。已发出的请求可能已计费。
- 内部执行段自动衔接；到达任务总预算时显示已暂停，可点击「继续处理」，也可直接输入新问题，无需先结束旧任务。
- 实时连接短暂断开时自动恢复同一个任务状态，不重新发送问题，也不重复调用模型。恢复过程中显示连接状态，允许立即重连。
- 密钥、余额、限流、服务超时等问题分别提示。未知付费状态的请求不自动重放；确认原因后可手动重新尝试。启动响应丢失时自动按原请求编号查询，暂时未登记会继续核对；可以编辑下一个问题，原请求身份保持不变。需要手动重试时使用「重试本次发送」，避免重复创建任务。
- 一个来源编号有误时保留回答正文，明确说明引用缺口，不生成虚假的可核对来源。专业结论仍需查看有效原文依据。
- 资料范围、相关版本或服务已变化时，旧进度不能绕过核验；可重新发送问题使用当前范围。
- 应用退出后，不自动恢复可能收费的执行。旧任务缺少有效检查点时需重新发问，已有记录继续保留。
