# 资料内容索引使用指引

更新日期：2026-10-23。

本机后台内容索引无需配置 AI 密钥，即可用正文中的词查找已建立索引的个人资料。R1 支持组合关键词、按相关性排序，并显示命中摘录、来源类型和可用位置。[AI 资料卡](AI资料卡使用指引.md)是可选的结构化理解，生成后作为线索参与检索。原有摘录检索线索入口保留为兼容工具。

**状态区分（2026-10-21）：** [AI 预整理](AI预整理使用指引.md)的“AI 已预整理 · 待确认”表示整理建议已生成。本页的索引状态表示原文提取和可搜索覆盖，两者不能互相替代，也不意味着资料已经进入文档库。

使用应用菜单「退出」完全退出旧版 TeamHub，再双击项目根目录的 `启动TeamHub.app`；仅关闭窗口可能仍在后台运行。当前默认独立包为 `dist-electron/retrieval-foundation-2026-10-23/mac-arm64/TeamHub.app`，沿用正常个人资料库配置，本轮交付验证见[AI 整理与准确检索第一阶段验收](../reviews/AI整理与准确检索第一阶段验收-2026-10-23.md)。索引第一步的历史包与验证留底见[第一步验收](../reviews/资料索引第一步验收-2026-10-15.md)。

## 怎么使用

1. 启动更新后的 TeamHub，收录资料。已有待整理和文档库资料也会逐步补建索引；首次启动资料较多时需要等待。
2. 在「待整理 → 整理」窗口或「文档详情」查看「资料内容索引」。正常整理可以直接完成，不必等待解析或 AI。
3. 在待整理或文档库搜索框输入正文里的词，可用空格组合，例如 `5053 压力异常`。输入关键词后按相关性排序，也可切换既有排序。名称、描述、标签仍会参与匹配，原有状态、资料类型、目录、标签和收藏筛选继续限制结果范围。
4. 查看结果中的命中说明，区分「原文命中」「名称命中」「AI 资料卡线索」等来源。摘录用于定位；在索引卡片展开「查看原文单元」，核对文字与原文位置。卡片先显示前 20 条，不代表全部只索引了 20 条。
5. 需要结构化摘要、导航和检索表达时，使用「AI 资料卡」；预整理已生成卡片的资料无需重复分析。如需使用原有摘录增强，可在文档详情展开「原文摘录补充工具」，点击「补充摘录检索线索」；先查看确切摘录及目标服务，确认后生成。它只理解所展示摘录，不代表全文。

AI 配置沿用[AI 辅助整理设置](AI辅助整理使用指引.md)。本机正文解析不调用 DeepSeek；只有主动确认的增强会发往所示服务并可能产生费用。

普通词允许局部匹配，组合关键词会优先返回覆盖较多关键词的资料。数字或带数字的设备编号按边界核对，例如 `5053` 不会因正文只有 `50530` 而命中，`ZX-2048` 不会因正文只有 `ZX-20480` 而命中；`2026` 可以匹配日期 `2026-10-22`。生成的行号、页码或单元格位置不会被当作正文中的设备编号；真实工作表名称仍可参与匹配。关键词最多 512 字、16 个词，不支持布尔检索语法或通配符表达式。

[AI 伙伴](AI智能伙伴使用指引.md)的资料搜索也返回命中片段和可用位置。具有可信位置的原文片段会附带下一步阅读指引；伙伴实际读取并核对当前授权版本后，才可形成该轮原文来源。名称、标签、资料卡和人工补充的命中只是查找线索，搜索摘录本身不等于已阅读全文。

## 如何理解状态和版本

| 状态 | 含义 |
| --- | --- |
| 等待提取 / 正在提取 | 后台队列处理中，可继续整理 |
| 已建立 | 本次支持的文字和结构已提取，没有检测到未处理项；不代表 AI 理解了全部含义 |
| 部分可搜索 | 已提取文字可搜，另有图像、图表、超限或其他缺口，需核对原文件 |
| 提取失败 | 当前内容未能生成可用索引；查看提示，修复资料后重建 |

索引以卡片标明的**已保存版本**为准。外部编辑器保存工作文件后，如尚未形成 TeamHub 内容版本，修改暂不进入该索引；通过原版本保存流程建立版本后，索引后台更新。恢复 V1 后，搜索转向 V1 的内容。旧结果失效到新结果完成之间，正文搜索可能暂时找不到该资料，名称查找仍然可用。

解析产物保存后，原文单元分批发布，已经发布的当前片段可先参与搜索。发布尚未结束或原文存在缺口时，覆盖状态会提示不完整；搜索不到不代表剩余内容中没有相关资料。升级旧索引时，合法的当前全文结果在位置回填完成前继续参与查找；尚无可信片段位置的结果标为「原文（位置回填中）」，不提供虚构位置。原索引显示「已建立」与分批发布已经完成需要分别判断。

「重建本地索引」会重新解析当前版本，并清除旧摘录增强线索，需另行确认生成。修改名称、描述、标签或位置后，旧摘录增强因语境变化而失效；原文索引仍保留。独立保存的资料卡不会因重建原文索引或改变分类而丢失，仍按内容版本与理解规则判定有效。索引操作不会新增文件版本、改写原文件或自动修改人工标签。

## 当前支持与边界

- 普通文本保留行号；文字型 PDF 保留页号；DOCX/ODT 保留段落、表格位置；XLSX/ODS/CSV/TSV 保留工作表与单元格位置；PPTX/ODP 保留幻灯片顺序；HTML 提取可见正文、不加载关联资源。常用模板/宏扩展按只读内容兼容，宏和脚本不执行。
- 扫描件、图片、图形关系、图表、批注等尚未完整识别；会报告缺口。DOCX 不伪造页码；Excel 不执行公式，已有缓存可能过期。
- 整体文件夹和不支持格式会明确提示，仍可按原有名称、标签查找。
- 每份文件读取上限 32 MiB、PDF 最多 500 页、最多 5000 原文单元和 100 万字符；其他解压、解析安全限额也会产生部分结果或失败提示。
- R1 的续跑覆盖解析产物已经落盘后的分批发布，重启可从已提交批次继续；解析产物落盘前的中断仍可能需要重新解析。它没有提高上述读取和解析限额，也不是超限文档的逐页解析续跑。
- 旧「补充摘录检索线索」单次最多发送 32 个完整单元、合计 12000 字符以内的展示负载；不足以覆盖全文时会提示。该工具的概览与辅助词只代表该次摘录。独立资料卡通过 Hermes 按需分段阅读，使用另一套任务预算与覆盖记录。
- 当前搜索使用正文词句、辅助词、有效资料卡及人工补充匹配，尚无向量语义检索或组织云仓库索引。AI 伙伴可以进一步理解问题和补查，但找不到不代表资料一定不存在。

索引保存在当前个人库的 SQLite 派生表中，与资料、版本关联；随原资料库备份和迁移一起保留。回收站资料不参与正文查找；永久删除会清理其索引关联。无须手工维护或删除这些表。

2026-10-16 解析器升级至 v2，旧派生索引会重新排队，不改变资料版本。上述“图像未索引”不表示伙伴不能看图；[AI 伙伴](AI智能伙伴使用指引.md#reading-formats)可以在任务授权后按需读取 PDF 原页、独立图片和办公文档内嵌位图。普通聊天中的看图结果不会自动写入全文索引；主动生成资料卡时，已实际理解的图像内容可随卡片保存并参与检索，其来源和缺口仍可核对。

本轮验证使用隔离资料库、合成文件和本机假服务，检查排序、编号边界、版本与授权、回填及发布恢复等工程行为；真实资料的解析覆盖、检索准确率和使用收益仍需通过试用验证。
