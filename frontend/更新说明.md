# 前端更新说明

## 更新内容

已将应用重构为两个独立页面，提升用户体验：

1. **文件上传页面** (`/upload`) - 专门用于文件上传
2. **文件列表页面** (`/files`) - 包含搜索和文件列表功能

## 新增功能

- ✅ 使用 Vue Router 实现页面路由
- ✅ 顶部导航栏，可在两个页面间快速切换
- ✅ 上传成功后自动跳转到文件列表页
- ✅ 支持从上传页跳转到文件列表页并自动搜索文件

## 安装新依赖

**重要：首次使用需要安装新的依赖包**

```bash
cd frontend
npm install
```

这会自动安装 `vue-router` 依赖。

## 使用说明

### 页面导航

- 点击顶部导航栏的"文件列表"或"上传文件"按钮切换页面
- 点击 Logo 可以返回文件列表页

### 文件上传流程

1. 点击"上传文件"进入上传页面
2. 添加标签
3. 选择或拖拽文件
4. 点击"开始上传"
5. 上传成功后自动跳转到文件列表页

### 文件搜索流程

1. 在文件列表页使用搜索框输入关键词
2. 或点击标签进行筛选
3. 搜索结果实时更新

## 路由说明

- `/` - 默认跳转到 `/files`
- `/files` - 文件列表页面（搜索 + 列表）
- `/upload` - 文件上传页面

## 注意事项

- 确保已运行 `npm install` 安装新依赖
- 如果遇到路由问题，请刷新浏览器页面
- 上传成功后会自动跳转，无需手动切换页面
