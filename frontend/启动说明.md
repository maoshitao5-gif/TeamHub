# 前端启动说明

## 前置要求

1. 确保已安装 Node.js (版本 >= 16.0.0)
2. 确保后端服务已启动并运行在 `http://localhost:8080`

## 快速启动

### Windows 系统

```bash
# 1. 进入前端目录
cd frontend

# 2. 安装依赖（首次运行）
npm install

# 3. 启动开发服务器
npm run dev
```

### macOS/Linux 系统

```bash
# 1. 进入前端目录
cd frontend

# 2. 安装依赖（首次运行）
npm install

# 3. 启动开发服务器
npm run dev
```

## 访问应用

启动成功后，浏览器会自动打开，或手动访问：

**http://localhost:5173**

## 常见问题

### 1. 端口被占用

如果 5173 端口被占用，Vite 会自动尝试下一个可用端口，请查看终端输出的实际端口号。

### 2. 无法连接后端

- 确保后端服务已启动：`python main.py`
- 检查后端是否运行在 8080 端口
- 检查防火墙设置

### 3. 依赖安装失败

```bash
# 清除缓存后重新安装
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```

### 4. 跨域问题

后端已配置 CORS，如果仍有问题，请检查：
- 后端 `main.py` 中的 CORS 配置
- 浏览器控制台错误信息

## 开发命令

```bash
# 开发模式（热重载）
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

## 项目结构说明

- `src/App.vue` - 主应用组件
- `src/components/` - 页面组件
- `src/api/` - API 请求封装
- `src/utils/` - 工具函数

## 技术栈

- Vue 3 (Composition API)
- Vite (构建工具)
- Element Plus (UI 组件库)
- Axios (HTTP 客户端)
