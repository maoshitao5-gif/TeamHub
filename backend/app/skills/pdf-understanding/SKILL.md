# PDF 与扫描件

沿用公共资料卡规则。先查看页数和可读内容结构，再决定文字或视觉路径。文字型 PDF 先读正文；扫描件或图形主导页使用当前可用的原页视觉读取。部分页有文字不代表其他页可解析，也不代表已读懂连线、印章、图例和表格布局。文件扩展名或提取失败均不能证明 PDF 中没有内容。

长文结合目录、适用范围、结论及例外选择页段；图纸先核对图名、图号、版次、页号、设备代号和图例。图上实际画出的连接、文字描述的功能和推测运行状态分别保存。模糊交点、不可辨认符号和缺少相邻页应记缺口，不按行业常识补成确定线路。事实来源使用实际工具返回的页号与定位，印刷页码不等于电子页序时分别说明。

扫描表和 OCR 文字中的负号、小数点、数字字母、单位和设备编号容易误读；重要值对照可见原页，仍不清晰则保留不确定性。原页无可读刻度时不按图形长度估值。模型不支持图像或页渲染失败时继续可读部分，清楚标记未识别范围；加载更多 Skill 不能补出视觉能力。

例：第 2 页正文描述检修方案，第 8 页接线图未读，可提取方案用途和第 2 页事实，不能写已核实接线正确。例：图纸标号可能是“Q1”或“O1”，缺少其他证据时保留待核对位置，不能任选一个当检索事实。加密、损坏或缺页依据工具结果报告，不猜口令、不绕过保护。
