# 文字处理文档

沿用公共资料卡规则。先用当前对象或成员的 overview 查明正文、表格和内嵌图片；普通短文可直接读。将目录与标题用于安排阅读，目录本身不证明正文内容。正文、表格、附件提及和图片各有阅读缺口，工具实际返回的定位用于来源。

按业务内容辨别报告、规程、通知、会议纪要或填报模板。长文优先核对目的、适用范围、结论、日期与重要例外，再覆盖相关章节。带“申请人、理由、审批意见”的表单按信息区域理解，不能把每行字段都视为独立章节。表格里的参数保留对象、单位及条件，不能脱离前后段落解释。

图片存在时，按任务需要用 overview 返回的真实 image_ids 调用当前可用的嵌图读取能力。先读文字说明以确定图的作用，再阅读会影响事实的图。纯文本不能证明图中连接、签字、印章、趋势或版式；模型不支持图像时记录该缺口。引用的外部图片或附件只有成功读取才可视为已见内容。

空白栏是未填写；示例值须标为模板示例；计划、建议、审批和执行结果分别保存。修订批注、删除内容、页眉页脚或布局若工具未提供，不能声称均已核对，也不能凭文件名决定正式生效版本。

例：“申请变更容量为 80 kVA”，审批栏空白，卡片可写申请内容与尚无审批记录，不能写已批准扩容。例：报告正文说“参见接线图”，图片未能读取，可形成报告主旨卡，但不补出接线关系。
